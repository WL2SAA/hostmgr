# Core Features

Capabilities included in the ecosystem.

Pterodactyl Management

Automates the installation, updating, user creation, and uninstallation of the Pterodactyl Panel and Wings.

VPS Management

Comprehensive QEMU-based VM manager to create, run, and manage local Linux VMs (Ubuntu, Debian, Fedora) with cloud-init.

Panel Customization

Easily install the Blueprint framework and associated themes/extensions to visually enhance your panel.

Networking Tools

Quickly deploy Cloudflare Tunnels for secure public access, and Tailscale for robust private networking without opening ports.

Database Setup

Streamline database workflows. Quickly create MySQL/MariaDB users, configure databases, and securely enable remote access.

System Utilities

View critical system information, monitor resource usage, and manage background services through a unified TUI.

# Scripts Overview

Directory of executable components.

--- Primary Entry Points ---

hostmgr.sh

The central management script for hosting services. Provides a robust TUI to access functionalities related to Pterodactyl, networking, and databases.

vps.sh

Comprehensive QEMU-based VM manager. Create, start, stop, delete, edit, and resize local Linux VMs. Supports cloud-init configurations.

--- Component Scripts ---

./panel2.sh

Lifecycle management of Pterodactyl Panel: install, administrative user creation, updates, and removal.

./wing2.sh

Installation and configuration of Pterodactyl Wings, Docker setup, and daemon auto-configuration.

./uninstall2.sh

Safe and complete removal utility for Pterodactyl Panel and/or Wings. Purges services and databases.

./Blueprint2.sh

Installer for the Blueprint framework to extend Pterodactyl Panel with themes and extensions.

./cloudflare.sh

Installs Cloudflare Tunnel (cloudflared) to securely expose your panel without opening firewall ports.

./Tailscale.sh

Installer and uninstaller for Tailscale, a zero-config VPN for creating secure private networks.
